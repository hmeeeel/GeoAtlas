# GeoAtlas

Учебный клиент-серверный проект «GeoAtlas»: сборщик данных (OpenStreetMap, Wikidata, OpenTripMap) - PostgreSQL - GraphQL-сервер - React-клиент с картой Яндекса.

```
db/          миграции (knex), подключение к БД
server/      GraphQL-сервер (graphql-yoga): схема, репозитории, сервис, загрузчики
collector/   сборщик данных: источники, конвейер, планировщик
client/      React + MUI + Apollo Client + Яндекс Карты v3
```

## ТЗ

- Взаимодействие backend и frontend только через GraphQL.
- Автоматизированный сбор данных минимум из 3 источников. Большой объем (не менее 10000 записей) и разнообразие данных.
- Различные типы операций. Несколько уровней вложенности, динамическое формирование.
- Фильтрация, сортировка, поиск и пагинация.
- Высокая производительность и отказоустойчивость.
